# Design

## Decisions

### 1. 行動用頻道按鈕，選目標用第二組按鈕

輪到的人在頻道看到行動按鈕（收入、外援、政變、稅收、刺殺、勒索、交換）；需要目標的行動按下後再出現選目標的按鈕。只有輪到的人能按。

### 2. 反應視窗

宣稱角色的行動和可以阻擋的行動，宣告後開一個 20 秒的反應視窗，頻道貼出「質疑」「阻擋」按鈕（只有能做的人按了才算）。第一個有效的反應就處理；20 秒沒人反應就執行行動。阻擋宣告後再開一個 20 秒視窗讓人質疑阻擋。

### 3. 私訊

手牌、失去影響力時選要翻哪張、大使交換時選要留哪兩張，都用私訊按鈕。

### 4. 計時

| 階段 | 時間 | 超時 |
|---|---|---|
| 選行動 | 60 秒 | 收入（10 枚以上時對隨機一人政變） |
| 選目標 | 30 秒 | 隨機目標 |
| 反應視窗 | 20 秒 | 沒人反應，繼續 |
| 選要翻開的牌 | 30 秒 | 隨機一張 |
| 大使交換 | 30 秒 | 留原本的牌 |
