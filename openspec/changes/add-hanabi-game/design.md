# Design

## Decisions

### 1. 看牌用 ephemeral

頻道的回合訊息附上「👀 看牌」按鈕，任何玩家按了都會收到只有自己看得到的訊息：其他人的手牌（顏色＋數字）和自己每張牌已知的提示（例如「第 2 張：紅、? 」）。不用每回合私訊每個人，避免洗版。

### 2. 出牌、棄牌用按鈕；提示用 slash command

輪到的人在頻道看到「出第 N 張」「棄第 N 張」按鈕。提示要選人和內容，用 `/game hanabi hint @某人 <紅|黃|綠|藍|白|1～5>` 比較直接。

### 3. 計時

每回合 2 分鐘。超時：提示標記不滿 8 個就棄掉最舊的牌（第 1 張）；滿 8 個就對下一位玩家隨機給一個有效的提示。
