# Spec Delta

## MODIFIED Requirements

### Requirement: 重要時刻的公告附上 GIF
下面這些時刻的頻道公告 SHALL 附上一張 GIF：

| 時刻 | 遊戲 | 說明 |
|---|---|---|
| 遊戲開始 | 全部 | 發牌之後的開始公告 |
| 天黑 | 狼人殺 | 每一夜開始時 |
| 天亮：有人死亡 | 狼人殺 | 昨晚有人死亡 |
| 天亮：平安夜 | 狼人殺 | 昨晚沒有人死亡 |
| 放逐 | 狼人殺、誰是臥底 | 有玩家被放逐（誰是臥底放逐到臥底時改用「抓到了」） |
| 狼王開槍 | 狼人殺 | 狼王開槍帶走玩家 |
| 平票 PK | 狼人殺、誰是臥底、間諜危機 | 投票平票、宣布進入 PK |
| 抓到了（決鬥成功） | 狼人殺、誰是臥底、間諜危機、阿瓦隆 | 騎士決鬥到狼人；誰是臥底放逐到臥底；間諜危機指控到間諜；阿瓦隆刺客刺中梅林 |
| 抓錯了（決鬥失敗） | 狼人殺、間諜危機、阿瓦隆 | 騎士決鬥到好人；間諜危機指控到平民；阿瓦隆刺客刺錯人 |
| 猜對了 | 誰是臥底、間諜危機 | 白板猜中平民詞；間諜猜中地點 |
| 猜錯了 | 誰是臥底、間諜危機 | 白板猜錯或沒猜；間諜猜錯或沒猜 |
| 隊伍通過 | 阿瓦隆 | 組隊投票通過 |
| 隊伍被否決 | 阿瓦隆 | 組隊投票沒通過 |
| 任務成功 | 阿瓦隆 | 公布任務成功 |
| 任務失敗 | 阿瓦隆 | 公布任務失敗 |
| 進入刺殺 | 阿瓦隆 | 好人完成 3 個任務、刺客準備刺殺 |
| 好人陣營獲勝 | 全部 | 遊戲結束 |
| 壞人陣營獲勝 | 全部 | 遊戲結束 |

如果某個時刻直接讓遊戲結束（例如間諜猜地點、阿瓦隆刺殺、誰是臥底最後一位臥底被放逐、白板猜中），這個時刻的 GIF SHALL 改附在遊戲結束的公告上、取代勝利 GIF，同一次結束 SHALL NOT 連續出現兩張 GIF。

每個時刻 SHALL 設定至少 10 張 GIF，每次公告時隨機選一張，所有 GIF 不重複。GIF 使用 Giphy 的公開網址，網址清單 SHALL 集中放在一個設定檔裡，不改程式碼就能替換。某個時刻沒有設定 GIF 時，公告 SHALL 只顯示文字，不會出錯。GIF SHALL NOT 透露任何隱藏資訊（例如死者的角色、死因、誰出了失敗）。

#### Scenario: 天黑公告附上 GIF
- **WHEN** 第 1 夜開始
- **THEN** 頻道公告「第 1 夜，天黑請閉眼」的下方有一張「天黑」的 GIF

#### Scenario: 平安夜和有人死亡用不同的 GIF
- **WHEN** 昨晚是平安夜
- **THEN** 天亮公告附上「平安夜」的 GIF，而不是「有人死亡」的 GIF

#### Scenario: 騎士決鬥成功和失敗用不同的 GIF
- **WHEN** 騎士決鬥到狼人
- **THEN** 公布結果的公告附上「抓到了」的 GIF；決鬥到好人時則附上「抓錯了」的 GIF

#### Scenario: 阿瓦隆任務結果
- **WHEN** 阿瓦隆的任務失敗，遊戲還沒結束
- **THEN** 公布任務結果的公告附上「任務失敗」的 GIF

#### Scenario: 阿瓦隆組隊投票
- **WHEN** 組隊投票通過
- **THEN** 公布通過的公告附上「隊伍通過」的 GIF；被否決時附上「隊伍被否決」的 GIF

#### Scenario: 間諜被指控
- **WHEN** 間諜危機指控到間諜
- **THEN** 公告附上「抓到了」的 GIF，接著間諜進入最後一次猜地點

#### Scenario: 造成結束的時刻不重複附 GIF
- **WHEN** 間諜猜中地點，遊戲結束
- **THEN** 遊戲結束的公告附上「猜對了」的 GIF，而不是勝利 GIF；猜地點的那則公告不附 GIF

#### Scenario: 刺殺梅林
- **WHEN** 阿瓦隆刺客刺中梅林
- **THEN** 遊戲結束的公告附上「抓到了」的 GIF；刺錯人時附上「抓錯了」的 GIF

#### Scenario: 多張 GIF 隨機選
- **WHEN** 「天黑」設定了 3 張 GIF
- **THEN** 每次天黑公告會從這 3 張中隨機選一張

#### Scenario: 沒有設定 GIF
- **WHEN** 某個時刻的 GIF 清單是空的
- **THEN** 公告只顯示文字，遊戲照常進行
