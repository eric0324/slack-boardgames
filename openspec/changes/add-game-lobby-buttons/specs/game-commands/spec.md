# Spec Delta

## MODIFIED Requirements

### Requirement: 遊戲清單與使用說明
使用者輸入 `/game`、`/game help`，或輸入不認識的遊戲代號時，系統 SHALL 只讓這位使用者看到「遊戲大廳」：所有可以玩的遊戲各一列（遊戲名稱、代號、人數、一句介紹）並附上「開房」按鈕，以及 wiki 連結和「輸入 `/game <代號> help` 看指令」的提示。按下某款遊戲的「開房」按鈕 SHALL 等同輸入 `/game <代號> new`：按的人成為房主；頻道已經有進行中的遊戲時 SHALL 拒絕並只讓按的人看到「這個頻道已經有遊戲了」。輸入 `/game <遊戲> help` 時，系統 SHALL 只讓這位使用者看到該遊戲的條列式指令說明。

#### Scenario: 查看遊戲清單
- **WHEN** 使用者輸入 `/game`
- **THEN** 只有這位使用者看到所有遊戲（狼人殺、誰是臥底、間諜危機、阿瓦隆、機密代號、吹牛骰、一字千金、政變、花火）的名稱、代號、人數、介紹和「開房」按鈕

#### Scenario: 從大廳開房
- **WHEN** 使用者在大廳按下吹牛骰的「開房」
- **THEN** 頻道出現吹牛骰的房間公告，按的人是房主

#### Scenario: 頻道已經有遊戲
- **WHEN** 頻道正在玩狼人殺，使用者在大廳按下政變的「開房」
- **THEN** 系統拒絕，只讓這位使用者看到「這個頻道已經有遊戲了」

#### Scenario: 查看誰是臥底的指令
- **WHEN** 使用者輸入 `/game undercover help`
- **THEN** 只有這位使用者看到誰是臥底所有指令的條列說明

#### Scenario: 查看間諜危機的指令
- **WHEN** 使用者輸入 `/game spyfall help`
- **THEN** 只有這位使用者看到間諜危機所有指令的條列說明

#### Scenario: 查看阿瓦隆的指令
- **WHEN** 使用者輸入 `/game avalon help`
- **THEN** 只有這位使用者看到阿瓦隆所有指令的條列說明

#### Scenario: 查看機密代號的指令
- **WHEN** 使用者輸入 `/game codenames help`
- **THEN** 只有這位使用者看到機密代號所有指令的條列說明
