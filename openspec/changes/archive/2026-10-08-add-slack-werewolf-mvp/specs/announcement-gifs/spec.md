# Spec Delta

## Purpose

在遊戲的重要時刻，讓頻道公告帶上 GIF 動畫和 emoji，讓只有文字的遊戲流程更有氣氛，也更容易一眼看出現在進行到哪個階段。

## ADDED Requirements

### Requirement: 重要時刻的公告附上 GIF
下面這些時刻的頻道公告 SHALL 附上一張 GIF：

| 時刻 | 說明 |
|---|---|
| 遊戲開始 | 發牌之後的開始公告 |
| 天黑 | 每一夜開始時 |
| 天亮：有人死亡 | 昨晚有人死亡 |
| 天亮：平安夜 | 昨晚沒有人死亡 |
| 放逐 | 有玩家被放逐 |
| 狼王開槍 | 狼王開槍帶走玩家 |
| 平票 PK | 放逐投票平票、宣布進入 PK |
| 騎士決鬥成功 | 騎士決鬥到狼人，公布狼人出局 |
| 騎士決鬥失敗 | 騎士決鬥到好人，公布騎士出局 |
| 好人陣營獲勝 | 遊戲結束 |
| 狼人陣營獲勝 | 遊戲結束 |

每個時刻 SHALL 可以設定多張 GIF，每次公告時隨機選一張。GIF 使用 Giphy 的公開網址，網址清單 SHALL 集中放在一個設定檔裡，不改程式碼就能替換。某個時刻沒有設定 GIF 時，公告 SHALL 只顯示文字，不會出錯。GIF SHALL NOT 透露任何隱藏資訊（例如死者的角色、死因）。

#### Scenario: 天黑公告附上 GIF
- **WHEN** 第 1 夜開始
- **THEN** 頻道公告「第 1 夜，天黑請閉眼」的下方有一張「天黑」的 GIF

#### Scenario: 平安夜和有人死亡用不同的 GIF
- **WHEN** 昨晚是平安夜
- **THEN** 天亮公告附上「平安夜」的 GIF，而不是「有人死亡」的 GIF

#### Scenario: 騎士決鬥成功和失敗用不同的 GIF
- **WHEN** 騎士決鬥到狼人
- **THEN** 公布結果的公告附上「騎士決鬥成功」的 GIF；決鬥到好人時則附上「騎士決鬥失敗」的 GIF

#### Scenario: 多張 GIF 隨機選
- **WHEN** 「天黑」設定了 3 張 GIF
- **THEN** 每次天黑公告會從這 3 張中隨機選一張

#### Scenario: 沒有設定 GIF
- **WHEN** 某個時刻的 GIF 清單是空的
- **THEN** 公告只顯示文字，遊戲照常進行

### Requirement: 公告加上 emoji
頻道公告 SHALL 在開頭加上代表這個階段的 emoji：遊戲開始 🎲、天黑 🌙、天亮 ☀️、討論 💬、投票 🗳️、平票 PK ⚔️、放逐 🚪、狼王開槍 🔫、好人陣營獲勝 🎉、狼人陣營獲勝 🐺、取消遊戲 🛑。

#### Scenario: 天亮公告有 emoji
- **WHEN** 天亮公布死訊
- **THEN** 公告以「☀️」開頭

### Requirement: 開始公告提醒查看私訊
遊戲開始的頻道公告 SHALL 提醒玩家「身分已經用私訊傳給每個人，請到和 bot 的私訊查看」，並附上 GitHub wiki 上「狼人殺-遊戲規則」頁面的連結。

#### Scenario: 開始公告提醒查看私訊
- **WHEN** 遊戲開始
- **THEN** 頻道的開始公告裡有提醒玩家查看私訊的文字

#### Scenario: 開始公告附上規則連結
- **WHEN** 遊戲開始
- **THEN** 頻道的開始公告裡有可以點的「遊戲規則」連結，指向 https://github.com/eric0324/slack-boardgames/wiki/狼人殺-遊戲規則
