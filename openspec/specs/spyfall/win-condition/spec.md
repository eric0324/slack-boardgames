# spyfall/win-condition Specification

## Purpose
判斷間諜危機的勝負：平民要指控到間諜並撐過間諜最後的猜測，間諜要躲過指控或猜中地點；遊戲結束時公開地點、間諜和每個人的角色，並提供再來一局。

## Requirements

### Requirement: 勝負判定
系統 SHALL 依照下面的規則判斷勝負，勝負一確定遊戲就結束：
- 被指控的是平民，或沒有人被指控：間諜獲勝
- 被指控的是間諜：間諜猜地點，猜中間諜獲勝，猜錯或 60 秒內沒猜平民獲勝
- 間諜在提問階段主動猜地點：猜中間諜獲勝，猜錯平民獲勝

#### Scenario: 指控錯人
- **WHEN** 被指控的 C 是平民
- **THEN** 頻道公告 C 是平民，間諜獲勝

#### Scenario: 抓到間諜且間諜猜錯
- **WHEN** 被指控的 D 是間諜，D 猜錯地點
- **THEN** 平民獲勝

#### Scenario: 抓到間諜但間諜猜中
- **WHEN** 被指控的 D 是間諜，D 猜中地點
- **THEN** 間諜獲勝

### Requirement: 結束公開與再來一局
遊戲結束時，系統 SHALL 在頻道公告獲勝方、這局的地點、誰是間諜，以及每位平民的角色，並貼出「再來一局」按鈕；按鈕規則和其他遊戲相同（上一局的任何真人玩家都能按，開一個新的空的間諜危機房間，按的人當房主）。房主取消的遊戲 SHALL NOT 出現「再來一局」。

#### Scenario: 公開結果
- **WHEN** 遊戲結束，地點是夜市、間諜是 D
- **THEN** 頻道公告獲勝方、「地點：夜市」、「間諜：D」，並列出每位平民的角色

#### Scenario: 再來一局
- **WHEN** 遊戲結束後，上一局的玩家按下「再來一局」
- **THEN** 頻道出現新的間諜危機房間，房主是按按鈕的人
